Fix the `illuminated_only` filter in FOV searches. The illumination status was computed and used to decide whether a satellite had any visible point, but the returned points were then selected by field-of-view membership alone, so non-illuminated (eclipsed) positions were still included whenever the satellite had at least one illuminated point in the window. Illuminated and dark points are now selected consistently, so `illuminated_only=true` returns only illuminated positions.
