Added `/tools/ephemeris-data-at-epoch/` and `/tools/ephemeris-data-for-satellite-at-epoch/` endpoints that return the raw operator-provided ephemeris (all stored points) at a given epoch - for every satellite with coverage, or for a single satellite by NORAD id or name - as a compact Parquet file or a zip of per-satellite CSV files. Currently limited to Starlink satellites.
