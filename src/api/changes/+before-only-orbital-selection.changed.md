The bulk "at epoch" endpoints (`tles-at-epoch`, `omms-at-epoch`) and the FOV endpoints (`satellite-passes`, `satellites-above-horizon`) now select, for each object, the record nearest the requested epoch in either direction within a 14-day window. A new optional `before_only` parameter (default false) restores the previous "newest-before" snapshot rule, selecting the most recent record at or before the epoch.
